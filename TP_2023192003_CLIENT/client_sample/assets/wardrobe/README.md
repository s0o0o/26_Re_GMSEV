# 옷장 원본 보관 (#55)

사용자가 제공한 Hamtaro: Ham-Ham Heartbreak 원본 시트를 source/에 변경 없이 보관한다. 게임 원작/시트 기여자 표기는 원본 이미지에 유지한다. 새 권리·배포 허가를 취득했다고 주장하지 않는다.

| 파일 | 현재 용도 |
| --- | --- |
| source/accessory-box-icons.png | 옷장 제목의 원본 아이콘. 카테고리 아이콘은 실제 캐릭터/눈/목도리 레이어 미리보기 사용 |
| source/dress-up.png | 액세서리 원본 확인·후속 방향별 레이어 제작 참고. 모든 항목 즉시 착용 구현 아님 |
| source/accessories-as-costumes.png | 원본 보관/후속 참고. 애니메이션과 정렬이 준비되기 전 임의로 캐릭터에 얹지 않음 |

현재 착용 가능한 항목은 assets/characters/의2캐릭터·털색5·눈3·목도리3이다. 옷장은 이 방향별 레이어와 서버 외형 동기화를 사용한다. 보관된 모든 액세서리의 구현 완료와 구분한다. 원본 해시는 source/SHA256SUMS에 기록한다. 원본 PNG는 변경하지 않고 실행 중 제목 아이콘의 배경색/프레임만 분리한다.
