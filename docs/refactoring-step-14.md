# 14. 커마 중앙 정렬과 아이콘 (#17)

기존 화면은 글자를 고정 좌표에 배치해서 길이가 다른 문구의 중심이 어긋났다.
`ui_alignment.hpp`에 SFML 글자 경계(left/top 포함)를 이용하는 `centerText`를
분리했다. 글자가 영역보다 길면 비율을 유지하며 축소한다.

- `hamster_customizer.cpp`: 제목, 캐릭터 이름 버튼, 색 이름, 안내를 중앙 정렬.
  눈/목도리 버튼의 위치도 같은 중심축에 맞췄다.
- 눈 옵션은 선택한 캐릭터·털색의 얼굴 일부를 보여준다.
- 목도리 옵션은 실제 목도리 레이어로 표시하며 미착용은 원/빗금 아이콘이다.
  새 그림을 생성하거나 장비 이름을 이미지에 박아 넣지 않았다.
- `client.cpp`: 로그인 입력 영역, 안내, 커마의 ID/닉네임,
  뒤로/접속/연결 중 버튼과 상태 문구를 영역 기준 중앙 정렬.
  배경 이미지 안에 그려진 타이틀 글자나 게임 HUD 배치는 변경하지 않았다.
- 서버 프로토콜, 선택 조작, 배경 블러와 로그인 흐름은 그대로 유지한다.

검증: 영문/한글 텍스트 경계 중심 자동 검사, 두 캐릭터 미리보기 및 실제
로그인/커마 화면 렌더링 확인, 회귀 테스트 7개와 클라이언트 Release x64 빌드 통과.
기존 수치 변환/중간 디렉터리 경고는 남아 있다. 실제 DB 접속은 실행하지 않았다.
