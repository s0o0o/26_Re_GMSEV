# 19. 클라이언트 접속 로딩 화면 (#21)

## 변경

이전에는 접속 중에도 커마 화면과 비활성 버튼만 표시했다.
`loading_screen.hpp`로 접속 전용 화면을 분리하고 ConnectingScreen에서 그린다.

- 기존 크림색 패널/갈색 테두리/픽셀 글꼴과 블러 배경 재사용.
- 선택한 캐릭터·털색·눈·목도리를 그대로 표시하고 시간 기반 수직 바운스 적용.
- 연결/로그인 전송/서버 응답 대기/수신 확인을 한글 문구로 구분.
- 점 5개를 순환해 대기 상태를 표시한다. 서버 진행률을 수신하지 않으므로
  실제 비율처럼 보이는 퍼센트나 채워지는 진행 막대는 사용하지 않는다.
- 닉네임/문구 가운데 정렬 유지. 접속 중 커마 조작 버튼은 숨긴다.
- 실패 시 기존 커마·오류 문구·재시도로 돌아가며 성공하면 기존 게임 상태로 전환.
- `HamsterCustomizer::drawBackdrop`를 분리해 로딩/커마가 같은 배경을 공유한다.

확인 클릭 후 로딩 화면을 먼저 표시한 뒤 기존 연결 작업을 수행한다.
TCP 연결(최대 2초)과 최초 리소스 로딩은 여전히 동기 작업이므로 그 구간에는
애니메이션이 일시 정지할 수 있다. 응답 대기 동안에는 프레임마다 움직인다.
서버 시작 자체의 로딩 창을 추가한 것은 아니다.

## 검증

- 4단계 로딩 화면 렌더링, 한글 표시와 배치 육안 확인.
- 실제 클라 코드+모의 서버 로그인 성공/거절/무응답/분할 패킷/재시도 테스트 통과.
- 회귀 테스트 10개 통과.
- 클라 Release x64 빌드 통과. 기존 수치 변환/중간 디렉터리 경고는 남아 있다.
- 실제 DB 접속 테스트는 실행하지 않았다. 기존 로그인 장애 #19와 별개인 UI 작업이다.
