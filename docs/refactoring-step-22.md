# 22. 야외 씨앗 채집과 몬스터 (#24)

## 이번 작업

`field_content.hpp`에 씨앗 3곳과 몬스터 3곳을 고정 배치했다.
클럽하우스는 안전 구역으로 유지한다. 몬스터 수량 설정은 이번 작은 지역에서
0~3마리로 제한한다. 기본 요청은 2000이어도 실제 생성은 최대 3마리다.

### 채집

- `initializeFieldMap`이 고정 씨앗 타일(4)을 배치한다. 피해/회복 랜덤 타일은 없다.
- 서버가 통과한 칸을 확인해 `collectSeed` 성공 시 씨앗 수를 1 증가시킨다.
- 맵 mutex 아래에서 4→0 변환을 검사해 동시 채집도 1회만 허용한다.
  송신·경로 탐색의 맵 읽기도 같은 동기화 경로를 사용한다.
- 획득자는 스탯/맵 응답을 받고 주변 플레이어에게도 맵 정보를 보낸다.
- 클라는 서버가 보낸 타일 상태를 간단한 픽셀형 씨앗 도형으로 표시한다.
  배경 그림 자체에 굽지 않아 소진 상태를 반영할 수 있다.
- 씨앗은 서버 실행 동안 한 번 채집 가능하며 재생성/월드 DB 저장은 아직 없다.

### 몬스터

- 야외의 유효한 고정 위치에 HP 5의 기존 HAM 몬스터를 최대 3마리 생성한다.
  기존 Lua 이벤트/무작위 이동/플레이어 공격에 따른 추격 흐름을 재사용한다.
- 무작위 이동에 충돌 검사를 추가하고 실내/출입 동선 진입을 제한한다.
- 지연된 추격은 대상의 접속 상태·야외 여부·다음 칸을 다시 확인한다.
  실내로 돌아간 플레이어를 따라가지 않는다. 추격 이동 시 섹터도 갱신한다.
- 이미 죽은 대상과 씨앗 부족 상태에서 추가 공격 소비를 막는다.
- 재활성화하며 발견한 Lua 콜백의 과도한 lua_pop(인자보다 많이 제거)을 없앴다.
  인자를 타입 검사하고 유효하지 않은 세션 접근도 방어한다.
- NPC 콜백과 추격 작업의 일부 조기 반환에서 작업 객체 누락도 정리했다.

자동 근접 공격·전투 전반 재설계·리스폰은 이번 범위가 아니다. 기존 공용 세션
레지스트리/모든 AI 상태의 동시성이나 다중 플레이어 전투 동기화 전체를 해결한 것은 아니다.

### 카메라 수정

이전 이동 패킷 처리의 카메라 제한이 후속 MAPINFO에서 원래 중앙 추적으로 덮였다.
서버 맵 청크와 클라 수신 모두 `world_layout::cameraX/Y`를 사용하게 통일했다.
맵 좌표를 화면 좌표로 변환하며 지역 전환 시 이전 채집 표시를 비운다.

## 검증

- 동일 씨앗에 16개 스레드 요청: 획득 1회와 소진 타일 확인.
- 스폰/귀환 동선/실내 차단, 기존 통행 및 포털 검사 통과.
- MAPINFO 이후 카메라 유지와 씨앗 타일 반영, 실제 SFML 표시 검사.
- 기존 테스트 포함 회귀 테스트 11개와 로그인 소켓 모의 테스트 통과.
- 실제 DB 없이 서버 시작 검사: Lua 몬스터 3개 생성 및 좌표 콜백 호출 통과.
- 서버·클라 Debug/Release 빌드 확인. 기존 경고는 남아 있다.
- 실제 DB 계정 접속/다중 플레이어 전투/장시간 AI 부하는 실행하지 않았다.
