# 일반 게임 클라이언트 로그인·재시도 검증

2026-11-15, 기준d085cef, [#19](https://github.com/s0o0o/26_Re_GMSEV/issues/19), 수정 [#47](https://github.com/s0o0o/26_Re_GMSEV/issues/47). 상태: AC-01~04 및 37개 회귀/Debug·Release 빌드/렌더러 검사 완료.

생산코드 테스트창이 아니라 일반 Release 실행파일에 computer-use로 입력한다. 기존 승인 계정900001299를 사용하며 실제 성공/종료 시 DB 저장이 발생한다. 추가계정/삭제/스키마 변경은 하지 않는다.

- AC-01: 최신서버/클라빌드와포트/실행파일확인. 일반exe에서숫자ID·닉네임입력→커마선택→입장동선을관찰한다. 전용계정이존재하는지COUNT로확인한다.
- AC-02: 서버가없거나무응답인실패를일반exe에서확인하고동일프로세스·선택을유지한채실제서버를시작하여재시도·GameScreen진입을확인한다. 모의무응답fixture를사용하면실제DB검증과구분한다.
- AC-03: 실제DB상태의입장/좌표/외형/이동을관찰하고클라이언트를닫았다가같은계정으로재접속한다. 서버connectionId와로그인단계/실패이유·송수신로그를함께확인한다.
- AC-04: 실제OS캡처와문서/이슈증거를남기고미실행은구분한다. 필요한수정이발견되면명세/이슈범위를갱신하고회귀를검증한다. 모두충족전#19를닫지않는다.

별도복수기기/모든입력기/장시간부하/과거사용자10053의최초원인확정은제외한다. 기존사용자프로세스를임의종료하지않고본작업에서띄운서버/fixture만정리한다. 시스템인증/보안UI는조작하지않는다.

구현 전 범위 추가(#47): 일반exe를workspace cwd에서실행하면Font Loading Error/exit-1로종료됨을확인했다. 실행파일주변의배포디렉터리/저장소client_sample루트를정해진후보로탐색하고폰트·main·캐릭터·맵자산이함께있을때만선택한다. 기존VS cwd는마지막fallback으로보존한다. 단위검사는가짜임시디렉터리의완전/부분/없음/다른cwd를검사하고,실제exe의프로세스시작폴더의존해소를UI로확인한다. 이부트스트랩수정은UI/패킷/DB스키마변경이아니다.
